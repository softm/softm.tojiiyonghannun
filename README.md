# 토지이용한눈

**Land Use at a Glance**는 지도 없이 주소만 검색해 토지이용계획의 핵심 내용을 확인하고, 선택한 필지를 토지이음 공식 원문으로 연결하는 웹 앱입니다.

## 실행

Node.js 20.18.1 이상이 필요합니다.

```bash
npm install
cp config.example.js config.local.js
npm start
```

`config.local.js`에 VWorld 인증키와 인증 도메인을 입력한 뒤 `http://localhost:4173`을 엽니다. 실거래 조회를 사용하려면 같은 파일의 `molitApiKey`에 공공데이터포털 일반 인증키를 입력합니다. 이 파일은 Git에서 제외됩니다. Node 서버 운영 환경에서는 파일 대신 `VWORLD_API_KEY`, `VWORLD_DOMAIN`, `MOLIT_API_KEY`, `PORT` 환경변수를 사용할 수 있습니다.

GitHub Pages의 `tojiiyonghannun.designboard.net`에서는 등록 도메인 전용 VWorld 브라우저 키와 JSONP를 사용해 주소·건물명·필지 검색을 직접 처리합니다. 토지이음은 CORS 허용 응답을 직접 조회하며, 보고서 지도는 CORS가 허용된 VWorld 항공·도로 타일을 브라우저에서 합성합니다. 브라우저 키는 공개 클라이언트 식별자이므로 반드시 해당 운영 도메인으로 제한된 키만 사용합니다.

## 기능

- 도로명·지번·건물명 통합 검색
- 검색 후보의 지번주소·도로명주소·PNU 확인
- 최근 조회한 필지를 브라우저에 최대 6개 저장하고 검색창 자동완성 또는 목록에서 바로 다시 조회
- 토지이음의 소재지, 지목, 면적, 지역·지구, 행위제한 근거 요약
- VWorld 공개 데이터 기반 개별공시지가 보완
- 선택 필지의 토지이음 공식 열람 화면 연결
- VWorld 일반·위성 지도에서 주소·건물명을 검색하거나 지도를 눌러 필지 경계를 확인하고 선택
- 조회 단계와 진행률 표시
- 조회 결과를 다중 페이지 PDF 뷰어로 미리보고 필요할 때 다운로드
- PDF 보고서에 선택 필지의 VWorld 항공·도로 혼합 주변 이미지 포함
- 토지·아파트·오피스텔·연립다세대·단독다가구·상업업무·공장창고 매매 실거래 참고 통계
- 선택 주소 복사와 대한민국 법원경매정보 공식 사이트 연결
- VWorld 건축물 목록과 국토교통부 건축물대장 원문 통합 보기
- VWorld 토지대장 공개정보의 지목·면적·소유구분·공유인수·지적도 축척·기준일 표시
- 통합 보기에서 건축물대장·토지대장·지적도 등본·공유지연명부·등기사항전부증명서·토지이용계획확인원 탭 제공
- 공개 API로 제공되지 않는 발급 문서는 정부24와 인터넷등기소 공식 경로 연결
- 서울 필지의 지구단위계획 지정이 확인된 경우 서울도시공간포털 상세정보 연결
- 개별 건축물 선택 시 건축물 생애이력 관리시스템 연결

건축물·토지대장 통합 보기는 외부 기관의 공개 원문 화면을 iframe 또는 새 창으로 연결합니다. 토지대장과 건축물대장은 국토교통부 원문 조회 화면에 POST 방식으로 필요한 PNU·본번·부번·건축물 식별정보만 전달하며, 외부 서비스의 세션 쿠키를 저장소나 소스에 보관하지 않습니다. 토지대장 공개 API는 소유구분과 공유인수만 표시하며 소유자별 성명·주소·지분은 수집하지 않습니다.

## 실거래 API와 Pages 배포

실거래 조회는 사용자가 `최근 24개월 조회`를 눌렀을 때만 국토교통부 공공데이터 API를 브라우저에서 호출합니다. 현재 2개월은 6시간, 그 이전 월은 7일 동안 브라우저 IndexedDB에 캐시하며 최대 200개 월별 항목을 유지합니다. 취소 거래는 통계에서 제외하고 별도 건수로 안내합니다.

GitHub Pages 배포에는 저장소 Secret `MOLIT_API_KEY`를 등록해야 합니다. 하나의 일반 인증키로 아래 7개 매매 API의 활용신청이 모두 승인되어 있어야 합니다.

- 토지 매매
- 아파트 매매
- 오피스텔 매매
- 연립다세대 매매
- 단독다가구 매매
- 상업업무용 부동산 매매
- 공장 및 창고 등 매매

Actions는 Secret으로 `runtime-config.js`를 생성하고 정적 배포물에만 포함합니다. 인증키는 저장소와 Actions 로그에는 기록하지 않지만, 정적 사이트가 브라우저에서 API를 직접 호출하므로 배포된 `runtime-config.js`와 브라우저 네트워크 요청에서는 확인될 수 있습니다. 공개되어도 되는 호출용 키라는 전제로 사용량 제한과 포털 모니터링을 함께 적용해야 합니다.

화면에 표시하는 내용은 참고용이며 공식 확인서를 대체하지 않습니다. 법적 효력이 필요한 경우 관계기관 확인 및 공식 문서 발급 절차를 이용해야 합니다.
