# 토지이용한눈 실거래가 분석 UX 및 공통 데이터 연결 (2026-11-17)

## 목표
단지명 반복 나열 대신 **현재 필지의 거래 의미와 비교 기준**을 먼저 보여준다. 감정평가액·시세·예측 가격처럼 오해될 수 있는 숫자를 생성하지 않는다.

## 구현 현황
- 전국 실거래 수집은 `softm/softm.tojihannun`에서 등록한 `realestate-data-001~020` 분산 수집 소스를 재사용한다.
- 지역 코드별 소유 샤드 매핑: `transaction-collected.js` (storage-registry revision twenty-shard-million-quota-v10).
- 공개 자료: `published/{법정동5자리}/{유형-sale}/index.json` → `published/{법정동5자리}/{유형-sale}/{YYYYMM}/{파트}.json.gz`.
- **수집 월의 게시·압축 원문이 정상 조회될 때만** 사용하고, 그 외 월은 기존 국토부 API/브라우저 캐시로 보완한다.
- 개별 월 청크 오류 시 해당 월 전체를 미확보로 처리하여 일부 행만 정상 월로 오인하지 않는다.
- UI는 자료 출처 사용 개월 수, 보완 실패 개월 수, 수집 갱신일을 표시한다.
- 기존 거래 차트와 목록을 유지하고 인사이트 박스·면적대별 비교를 추가한다.

## 사용자 관점 화면 순서
1. **거래 범위**: 동일 필지·단지 공개 거래인지, 동일 법정동 비교 거래인지 구분
2. **최근 거래**: 계약일, 면적, 층, 금액
3. **면적대별 비교**: 아파트/연립/오피스텔은 ±5% 면적군으로 묶고 거래금액 중간값/㎡당 중간값 제시
4. **가격 변화**: 최근 6개월 vs 직전 6개월, 양쪽 모두 3건 이상이고 결측월이 없을 때만 ㎡당 단가 변화 제시
5. **월별 그래프**: 날짜는 연도·월 표시. 차트는 실거래가 있는 달만 표시. 빈 달을 0원으로 간주하지 않음
6. **거래 내역**: 가격·계약일·전용면적·층·㎡당 가격을 우선, 같은 단지명 반복 최소화

## 후속 개선(P2)
- 전용면적 선택 버튼 59/74/84㎡ 등은 실제 확보된 면적 분포에서 자동 생성
- 3/6/12/24개월 기간 필터 및 그래프 전환
- 선택 면적대 최근 거래 대비 과거 분포(사분위 범위) 안내, 최소 5건 조건
- 자료 미수집/미게시/수집 오류/공개 거래 없음의 4가지 빈 상태 구분
- 공유 보고서에 비교 범위·출처·최종 갱신일 포함

## 운영 검증 필요
- 각 shard GitHub Pages 발행 여부 및 CORS/gzip 브라우저 지원을 확인해야 실제로 수집 JSON이 사용된다.
- `npm test`, `npm run build` 및 Pages 배포 성공 여부는 CI에서 확인한다.
- `realestate-data-*` 레지스트리 변경 시 정적 샤드 매핑을 재생성해야 한다.
- 부천 옥길동 아파트 등 실제 주소로 수집 JSON 사용 월 수 및 기존 API 결과 일치 여부 검증한다.
