# VWorld 운영키 재신청 정리

작성일: 2026-10-22

## 목적

VWorld 운영키 신청 반려 사유에 맞춰 실제 서비스 코드에서 사용하는 API만 신청하고,
기능화면 이미지와 대표이미지를 서로 다른 용도로 준비한다.

운영 서비스: https://tojiiyonghannun.designboard.net/

## 반려 사유 요약

1. 활용 API는 실제 서비스에서 사용하는 항목만 선택해야 한다.
2. 기능화면 이미지는 VWorld API를 실제 활용하는 서비스의 전체 화면으로 등록해야 한다.
3. 대표이미지는 기능화면과 다른 이미지로, 서비스/플랫폼 로고를 등록한다.

## 현재 코드 기준 VWorld 사용 현황

| 구분 | 실제 사용 | 코드 근거 | 운영키 신청 |
| --- | --- | --- | --- |
| 검색 API | 도로명주소, 지번주소, 건물명 검색 | `browser-api.js`의 `/req/search` | 선택 |
| 2D데이터 API | 연속지적도 필지 조회, 경계 GeoJSON 조회 | `browser-api.js`의 `/req/data` | 선택 |
| 국가중점 API | 개별공시지가, 건축물 정보, 토지대장 공개정보 | `/ned/data/getIndvdLandPriceAttr`, `getBuildingUse`, `ladfrlList` | 선택 |
| 배경지도/WMTS·TMS | 일반·영상·하이브리드 타일 표시 | `app.js`, `parcel-map.js`의 `xdworld.vworld.kr/2d/...` | VWorld 분류 확인 후 해당 항목만 선택 |
| 이미지 API | 운영 GitHub Pages에서는 미사용. 보고서 이미지는 타일 합성 | 서버용 `server.mjs`에만 `/req/image` 경로 존재 | 해제 |
| 지오코더 API | 별도 지오코더 호출 없음 | 검색 API 응답 좌표 사용 | 해제 |
| WMS/WFS API | 호출 없음 | 해당 엔드포인트 미사용 | 해제 |
| 범례 API | 호출 없음 | 해당 엔드포인트 미사용 | 해제 |
| 2D 지도 API | VWorld 전용 2D SDK 호출 없음. OpenLayers + 타일 사용 | `app.js` | 해제 |
| 3D 지도 API | 사용 없음 | 3D SDK 없음 | 해제 |
| 2D 모바일 API | 사용 없음 | 별도 모바일 SDK 없음 | 해제 |
| 3D 모바일 API | 사용 없음 | 별도 모바일 SDK 없음 | 해제 |
| 3D 데스크톱 API | 사용 없음 | 별도 데스크톱 SDK 없음 | 해제 |

### 지도 타일 항목
현재 서비스는 아래 형식의 VWorld 타일을 사용한다.

- `https://xdworld.vworld.kr/2d/Base/service/{z}/{x}/{y}.png`
- `https://xdworld.vworld.kr/2d/Satellite/service/{z}/{x}/{y}.jpeg`
- `https://xdworld.vworld.kr/2d/Hybrid/service/{z}/{x}/{y}.png`

운영키 신청 화면에서 이 사용 방식이 '배경지도 API' 또는 'WMTS/TMS API' 중 어느 분류인지 VWorld 기준을 확인한 후,
해당되는 항목 하나만 추가 선택한다. 사용하지 않는 항목을 중복 선택하지 않는다.

## 서비스설명 수정안

토지이용한눈은 도로명주소·지번주소·건물명을 검색해 대상 필지의 PNU와 위치를 확인하고,
연속지적도 기반 필지 경계를 지도에 표시하며, 개별공시지가·건축물 정보·토지대장 공개정보를
한 화면에서 확인할 수 있도록 제공하는 민간 토지정보 서비스입니다.
VWorld 검색 API, 2D데이터 API, 국가중점 API와 VWorld 배경지도 데이터를 활용합니다.

## 활용API 기능설명 수정안

1. 검색 API  
도로명주소·지번주소·건물명을 검색해 후보 주소, 좌표, 필지 식별번호(PNU)를 확인합니다.

2. 2D데이터 API  
선택한 위치의 연속지적도 필지 정보를 조회하고 지도에 필지 경계를 표시합니다.

3. 국가중점 API  
선택한 필지의 개별공시지가, 건축물 공개정보, 토지대장 공개정보를 조회하여 요약 정보로 제공합니다.

4. 배경지도/WMTS·TMS  
VWorld 일반지도·영상지도·하이브리드 배경지도를 지도 화면 및 보고서의 필지 주변 지도에 활용합니다.
※ 최종 항목명은 운영키 신청 화면의 분류 기준에 맞춰 하나만 선택합니다.

## 기능화면 이미지 준비 기준

기능화면 이미지는 일부 UI만 잘라내지 않는다.

권장 화면:
1. https://tojiiyonghannun.designboard.net/ 접속
2. 실제 주소 또는 지번 검색
3. 검색 결과에서 필지 선택
4. '지도에서 보기' 열기
5. VWorld 위성 또는 일반 지도와 선택 필지 경계가 함께 보이는 상태
6. 브라우저 전체 또는 서비스 전체 화면을 캡처

캡처에는 다음이 함께 보이는 것이 좋다.
- 토지이용한눈 서비스명
- 검색 또는 선택한 필지 정보
- VWorld 지도
- 선택 필지 경계
- 실제 서비스 UI

## 대표이미지 준비 기준

기능화면 캡처를 재사용하지 않는다.

대표이미지는 토지이용한눈 서비스 로고 또는 앱 아이콘을 사용한다.
배경은 단순하게 하고 서비스명이 읽히도록 구성한다.
